# 早苗能做什么

本文对应 2026-10-29 的公开源码。早苗也使用“八千代”这个名字：她是接在 LLBot / OneBot v11 上的群聊机器人，既能聊天，也能调用限定范围内的 QQ 和 Minecraft 工具。

下面写的是代码实现的能力。能否在你自己的群里使用，取决于模型接口、机器人群权限、服务器注册表和数据采集是否配置完成。本文参考了她在群里的自我介绍，但以源码核验结果为准，不把角色自述当成功能验收。

## 1. 像群友一样接话

- 支持 @、名字呼叫、引用回复，以及有条件的跟话。是否主动接普通群聊由本地社交规则和开关决定。
- 先区分闲聊、认真提问、资料总结和运维请求。闲聊可以短、直接、带吐槽；解释技术问题时保留必要事实与步骤。
- 同一个人连续发几条短文字，会短暂等一下再合并；“不是，我是说……”这类更正能替换尚未发出的旧回答。
- 能识别“先听我说完”“别分析”“不要一直追问”等明确表达，调整本次回应方式；告别时不为了续聊硬接新话题。
- 回复可以分成多个 QQ 气泡，最多 8 条。一般短回复保持一两条，8 条是上限，不是每次都发满。
- 表情包由本地素材目录和语义标签选择，有冷却和数量限制。素材需要自行准备，仓库不附带实际表情包收藏。

这部分依赖 [`social_lite.py`](../social_lite.py)、[`conversation_turns.py`](../conversation_turns.py)、[`sanae_persona.py`](../sanae_persona.py)、[`reply_lessons.py`](../reply_lessons.py) 和 [`sticker_catalog.py`](../sticker_catalog.py)。角色表现由模型、上下文和这些规则共同决定，调整一句角色卡不会保证所有对话都自然。

## 2. 记住人，也分清是谁说的

早苗的“记忆”分成几种用途：

| 内容 | 用来做什么 | 主要边界 |
| --- | --- | --- |
| 近期对话 | 接住上一句，理解短追问 | 按群、用户和权限上下文隔离，有容量和时间限制 |
| 个人事实与偏好 | 记住称呼、回复习惯等 | 保留原话、消息来源和时间，不把助手自己的话当用户事实 |
| 持续事件 | 记住某人正在做的事，以及后来完成或取消 | 必须有该人的来源证据；不把疑问、假设或别人的事记成他的经历 |
| 说话心得 | 根据“刚才太长了”“这句接得好”等反馈修正表达 | 绑定已成功送达的回答与反馈；只调整有限表达经验，不改权限或角色身份 |
| 管理员知识库 | 保存经管理员明确登记的公共知识 | 与个人记忆分开，可检索和删除 |

“早苗说过这件事”和“群友真的说过这件事”是两种证据。引用、转发、旧账号发言和机器人自身回复都要保留归属；未读图片不能变成已经读过的内容。记忆命令支持查看、记住、忘记等操作，具体语法由当前桥接命令返回。

主要实现：[`conversation_memory.py`](../conversation_memory.py)、[`reply_lessons.py`](../reply_lessons.py)、[`shared_knowledge.py`](../shared_knowledge.py)、[`sanae_identity.py`](../sanae_identity.py)。这是本地状态更新，不是在给基础模型继续训练，也不是机器人自行修改、部署生产代码。外部开发工具或维护任务不属于她的内建“自主进化”。

## 3. 读聊天记录，查清群里说过什么

可以问“刚才在讨论什么”“某人今天提过哪些问题”，也可以引用一条消息或合并转发让她解释。

- 从 OneBot 实际可读的本群记录中读取，支持日期、发言人、关键词等筛选。
- 保留原发言人、时间、引用与转发层次；区分转发人和原作者。
- 普通问题可以只给短结论；需要时整理主要话题、时间线、争议和待办。
- 说明本次的读取范围、截断与未读部分，不能拿一批样本当作完整群历史。

实现见 [`qq_chat_reader.py`](../qq_chat_reader.py)、[`chat_recall.py`](../chat_recall.py)、[`chat_summary.py`](../chat_summary.py)。群聊档案是部署机器上的私有数据，不随源码发布。

## 4. 看图、理解语音和视频

| 能力 | 实际行为 | 前提与限制 |
| --- | --- | --- |
| 明确看图 | 读取消息或引用中的图片，让视觉模型描述，再交给聊天模型回答 | 需要视觉接口；描述可能有误，图片里的字不是系统指令 |
| 静默看图 | 群里发图时在后台做短期观察，相关话题出现时补入上下文 | 需开启 `SANAE_SILENT_VISION`；只处理允许群，观察不直接进入长期记忆 |
| 语音转写 | 将可获取的语音转换为支持的音频格式，调用 ASR | 接口、密钥和开关单独配置；部分 QQ 音频需要 Silk 解码与 FFmpeg |
| 音频理解 | 可选调用音频理解接口，补充转写之外的描述 | 与 ASR 分开配置，不代表能识别所有声音 |
| 视频理解 | 可选调用视频接口，必要时使用有限关键帧 | 结果会注明局部关键帧，不是完整逐帧观看 |
| 群相册看图 | 读取指定相册的近期照片，再按请求描述 | 依赖 LLBot 相册扩展接口和视觉配置，单次观察有数量上限 |

相关代码：[`media_segments.py`](../media_segments.py)、[`media_transport.py`](../media_transport.py)、[`media_pipeline.py`](../media_pipeline.py)、[`silent_vision.py`](../silent_vision.py) 及 `sanae_ai.py` 的视觉调用。

“静默”表示不会立即发消息，仍可能调用外部视觉服务。以上主要是媒体输入与理解，不代表已经配置语音合成、实时语音通话、视频直播观看或图片生成。

## 5. 查网页、模组和本服配方

- **公开网页**：搜索资料并提取网页正文，回答保留来源。联网搜索使用单独的服务能力，文本模型切成 Gemini 不等于搜索服务也自动改成 Gemini。
- **B 站链接**：读取视频标题、UP 主、时长、简介和公开统计，识别短链与直播间信息。这是公开信息查询，不等于已经看完视频内容。
- **模组资料**：先查选定服务器实际安装清单，再组合 Modrinth、CurseForge、MC 百科等可用来源；区分“网上有这个模组”和“本服装了它”。
- **配方查询**：支持“这个怎么做”“这个能做什么”“这台机器能做什么”。用本服模组和数据包生成的索引查结果、材料、配方类型及部分机器条件。
- **配方变更提醒**：若相关物品在 KubeJS 脚本中出现，会提示脚本可能另有改动；静态索引不能保证等同运行中的完整配方表，也不保证包含所有原版或动态生成配方。
- **下载并上传群文件**：有受控的 Modrinth 下载路径，需要管理员在当前消息明确要求下载并发到群文件，并检查大小、来源和文件哈希。

主要实现：[`lookup_tools.py`](../lookup_tools.py)、[`recipe_index.py`](../recipe_index.py)、[`mod_lookup.py`](../mod_lookup.py)、[`mod_inventory.py`](../mod_inventory.py)、[`deepseek_features.py`](../deepseek_features.py) 和 `sanae_ai.py` 的工具入口。

## 6. QQ 群内的小动作和管理

这些操作通过 LLBot 的 OneBot 与扩展接口执行，接口不支持或账号权限不足时就不可用。

| 操作 | 谁可以请求 | 说明 |
| --- | --- | --- |
| 戳一戳、给消息贴表情回应 | 群友 | 受对象、请求者或群级频率限制 |
| 资料卡点赞 | 请求者本人 | 每日限次；QQ 平台也可能拒绝 |
| 查群文件、公告、精华、荣誉、相册 | 群友 | 读取本群资料；不等于能读取任意文件正文 |
| 查询禁言情况 | 群友看自己，群主/管理员看列表 | 依照实际 QQ 群角色限制 |
| 禁言、解除禁言 | 群主或管理员 | 机器人也必须具备群管理权限；目标不能是群主、管理员或机器人自己 |
| 撤回、设群精华 | 群主或管理员 | 针对可核验的本群消息；有机器人权限与被操作对象限制 |
| 将图片存入群相册 | 群主或管理员 | 需要明确图片消息与相册，单次最多 9 张 |

[`qq_interact.py`](../qq_interact.py) 在执行时重新查 QQ 群角色并解析目标。多人同名时先消除歧义，模型称呼某人“群主”不会赋予他权限。QQ 群管理权限与 Minecraft 运维管理员配置是不同的权限来源。

## 7. Minecraft：从现状到历史，再到受控操作

| 可以问什么 | 主要来源与时效 | 权限和限制 |
| --- | --- | --- |
| 在线玩家、TPS、MSPT、规则、状态 | RCON / 状态协议的当前查询 | 已配置服务器；失败时不能用模型记忆冒充实时值 |
| 最近是否卡顿、哪个时段负载高 | 已采集的时间序列与事件 | 只覆盖采集窗口，缺失数据不记为零 |
| 实体、机器、强加载、主机概况 | 实时查询、缓存或按需采样 | 明细与新采样有权限限制；采样相关性不等于已证明卡顿原因 |
| 网络线路、连接流量、数据包类型 | 服务器主机侧诊断、短期流量统计、JFR 采样 | 玩家流量明细和新数据包采样受管理员权限限制；不承诺零开销 |
| 玩家做过什么、去过哪里 | 事件、最近保存的统计、可选离散位置采样 | 轨迹限管理员；不能还原每个方块的变动或完整路线 |
| FTB 任务、成就、神秘时代研究 | 已支持格式的存档、任务书与镜像 | 存档值可能落后于当前游戏；不代表支持任意模组存档 |
| SI 市场行情与交易所审计 | 已支持的市场存档或只读命令 | 行情与个人账目区分，敏感明细按执行入口限制 |
| 这个物品、配方或配置从哪来 | 模组清单、静态索引、配置镜像 | 配置内容限管理员；镜像和索引需更新 |

管理员还可读取允许范围的日志、崩溃记录，查询本服命令语法，按权限执行低风险命令。其他管理命令需要目标核验和确认；自然语言“确认”也必须对应本人仍有效的待确认操作。问题台账、备份状态、周报和通知依赖对应配置与采集。

源码保留了 BlueMap 地图截图的历史声明与实现，但当前管理员和群友工具集均未注册它，因此不属于当前可调用能力。

核心模块包括 [`server_registry.py`](../server_registry.py)、[`rcon_ops.py`](../rcon_ops.py)、[`command_catalog.py`](../command_catalog.py)、[`sanae_local_ops.py`](../sanae_local_ops.py)、[`server_insight.py`](../server_insight.py)、[`server_network.py`](../server_network.py)、[`server_traffic.py`](../server_traffic.py)、[`player_trail.py`](../player_trail.py)。

通用的任意目录读取、任意文件读取和直接修改配置工具在 AI 分发中已停用。管理员的配置查询走限定镜像目录；能操作服务器不等于能让模型任意执行主机 Shell。

## 8. 哪些能力要主动开启

公开示例采用较克制的配置：

| 配置或依赖 | 公开示例状态 / 使用条件 |
| --- | --- |
| 普通聊天触发 | `SANAE_MENTION_ONLY=1`；名字呼叫默认关闭 |
| 主动插话 | `SOCIAL_LITE_SPONTANEOUS=0` |
| 静默看图 | `SANAE_SILENT_VISION=0`，使用前配置视觉服务 |
| 表达学习 | `SANAE_EXPRESSION_LEARNING=0`；不等于所有记忆都关闭 |
| 群消息转服 | `RELAY_G2S=0`；TPS 等主动查询仍可独立使用 |
| 服内事件监控 | `SANAE_ENABLE_LEGACY_MONITOR=0`；事件播报需额外配置 |
| 自动玩笑禁言 | `FUN_MUTE_AI=0`；与管理员明确请求的禁言工具不同 |
| 音频、视频理解 | 各接口、密钥与开关需分别配置 |
| 玩家轨迹、性能历史、周报等 | 需要对应采集器、存储和服务器能力，缺数据不当成零值 |
| 跨模型回落 | 需明确设置 `SANAE_TEXT_FALLBACK` 并配置备用服务 |

复制仓库不会自动复制运营中的角色私有资料、长期记忆、表情包、聊天记录、服务器数据和 API 凭据。部署方法见 [README](../README.md)，内部流程见 [技术实现](ARCHITECTURE.md)。
