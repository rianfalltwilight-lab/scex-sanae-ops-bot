## 对话和 QQ 互动

- 服务器回答后的追问按实际引用内容匹配，避免把同群另一段闲聊误接到服务器查询上。
  总结或工具回答后的短句评价能接到前一段结果，不再只看闲聊历史。
- 补充自然语言运维请求识别、管理通知、玩家绑定提示；普通询问不当成执行授权。
  天气查询通过受限读取实现，停服和重启仍进入已有确认流程。
- 新增 `qq_interact.py`：群文件、公告、精华、荣誉、相册、禁言状态的读取，以及戳戳、
  消息表情、名片赞等互动。禁言、撤回、设精华和存群相册另查当前 QQ 群身份及操作目标。
  OneBot 不支持的接口会失败，不会因为存在工具名就自动获得能力。
- 支持 QQ 商城表情的图片识别和明确要求下的相册图片理解；普通消息不会触发任意相册上传。
- 改进 Gemini 瞬时服务错误的有限重试、工具回合重放格式和超时处理；达到只读查询次数上限时，
  可以基于已有结果回答。模型已执行的操作不会因回落而从头重放。
- 延后中间等待提示，减少很快就能完成的查询先发一条“正在处理”。技术长回答与日常短气泡分别组织。

## 服务器能力

- `lookup_tools.py`：配方制造、用途、机器加工查询，模组安装与来源资料，B 站公开信息摘要。
  索引数量由各部署决定；动态配方和 KubeJS 改动仍需对照游戏内结果。
- `server_network.py`：从已配置服务器主机采集网络诊断，与机器人本机的 `!ping` 分开。
- `server_traffic.py`：连接流量采样与 JFR 数据包统计；普通成员看受限汇总或已有采样，
  管理员才可启动受限采样及查看玩家明细。缓存和自动停止不代表无性能开销。
- `player_trail.py`：可选后台位置采样，支持按玩家查轨迹或按区域找采样记录。
  仅管理员查询，采样间隔内的实际路线未知，大距离跳变也不直接证明作弊。
- `market_audit.py`：对接游戏内 SI 经济审计命令，区分公开概况与管理员审计信息。
- `backup_status.py`：查询备份是否成功及失败信息；新增代码使用可配置的备份工具目录，
  不随公开源码提供生产备份或删除权限。
- 世界查询补充玩家所在维度、指定方块实体统计和备份状态；进度/排行、只读远端文件读取、
  运维监控和服务控制同步近期修复。文件型数据按最近保存或同步时刻解释。

## 公开版修正与配置

发布前审阅发现“确定”的匹配可能把“不确定”等犹豫表达当成同意。本次公开版收紧确认否定门，
并增加工具执行层的拒绝回归。此修复留在公开副本；更新仓库不等于部署到现役进程。

| 配置 | 用途 |
| --- | --- |
| `GEMINI_RETRIES` | 默认 `2`，控制普通接口的额外瞬时错误重试；仍受整轮截止时间限制。鉴权、请求和配额错误不因此无限重试。 |
| `SANAE_INTERIM_DELAY` | 默认 `20` 秒，控制延后的中间等待提示。 |
| `PLAYER_TRAIL_ENABLED` | 默认 `0`，显式启用后才启动玩家位置采集。 |
| `PLAYER_TRAIL_SERVER` | 采集目标的注册表 ID，默认 `legacy`；应与实际配置匹配。 |
| `PLAYER_BINDINGS_SERVER` | 绑定游戏名时核对的服务器 ID，默认 `legacy`。 |
| `LEGACY_BACKUP_TOOL_DIR` | 备份工具状态所在目录；公开版默认仓库下 `backup-tool` 占位目录，未配置真实工具时不保证可用。 |

配置示例保留空身份/占位值、本机端点和显式开关。现役的启动脚本、账号、群路由、密钥、
服务器注册表和外部控制工具均不复制到 Git。玩家轨迹、审计状态和聊天仍写入部署自己的本地状态目录。

本仓库的记忆、持续事件与说话心得是对话数据和提示管理，不会自动修改自身源码、提升权限或部署新版本。
外部开发代理的定期审阅属于另一个运维流程，不是本仓库开箱即用的“自我递归升级”。
