# 2026-10-26 公开源码同步

本次同步本地近期迭代的源码及离线回归。生产启动配置、凭据、聊天、记忆、玩家数据、
镜像资源和游戏原文均留在部署机器上；旧版的公开配置接口和跨平台修复继续保留。

## 对话与模型

- Gemini 支持 SSE 响应拼接及拆分工具调用的合并，避免把传输分片当成 QQ 消息分段。
  流式路由不存在或出现部分服务端错误时，本次请求可改用普通接口；配额和鉴权错误不走此重试。
- 增加显式启用的 DeepSeek 回落。只在符合条件的首次模型调用失败时回落，已经调用过工具的
  对话不从头重放。聊天与后台 JSON 提取使用各自预算，后台任务不会把聊天思考档位调低。
- 区分群友原话、转发作者和助手自己的旧消息；需要讨论群主/管理员时读取真实 QQ 群角色，
  名片中的“群主”字样不作为权限或身份依据。
- 加入个人细节的重复提醒、旧上下文的相对时间，以及引用后的“我也要/行”等短句跟话提示。
  闲聊保持短口语，必要时最多 8 条气泡；它是上限，不是凑满 8 条的目标。
- 保留持续事件、个人记忆和回复心得；移除旧黑话/主题学习层，表达学习由独立开关控制。
  成功送达的助手回复可选按天保存，便于本地排查；归档内容不进入 Git。
- 补充工具标记泄漏、未执行却声称禁言、接口异常直出等回复修正。模型行为仍需真实对话验证，
  离线规则通过不代表每次回答都正确或自然。
- 发布前回归发现模组存在性提示已实现但未接入闲聊提示，本次补上该调用；只读取当前选定
  服务器的清单，缺失时不借用其他服务器的数据。还修复了引用服务器回答后，引用正文使短追问
  丢失工具路由的问题。这两处修复仅在公开源码副本中，未自动部署到线上。

## 新增或调整的配置

沿用 [基础配置说明](UPDATE-20261025.md)，示例见 [env.example.ps1](../examples/env.example.ps1)。

| 配置 | 行为 |
| --- | --- |
| `GEMINI_STREAM` | 默认 `1`；使用 Gemini 流式路由，最终仍按完整结果组织回复。 |
| `SANAE_TEXT_FALLBACK` | 默认空；设为 `deepseek` 才启用跨 provider 回落，需单独提供其密钥。 |
| `SANAE_EXPRESSION_LEARNING` | 示例为 `0`；关闭表达经验的新增和注入，保留已有文件。 |
| `SANAE_PRIVATE_FORWARD` | 示例为 `0`；不把私聊转发给 owner。 |
| `SOCIAL_REPLY_ARCHIVE` | 可选的助手回复归档目录，未配置时不启用此归档。 |
| `SOCIAL_REPLY_ARCHIVE_DAYS` / `SOCIAL_ARCHIVE_DAYS` | 默认 `365`；按各自目录保存日归档。 |
| `LEGACY_CRASH_NOTIFY_GROUPS` / `LEGACY_LAG_ALERT_GROUPS` / `LEGACY_UPDATE_NOTIFY_GROUPS` | 对应通知目的群；不填写则不发送该类通知。 |
| `FUN_MUTE_AI` | 默认及示例均为 `0`；按群权限、对象、时长、冷却和真实执行回执限制玩笑禁言。 |

公开示例关闭群消息转服及服内事件监控，TPS、状态等主动查询仍可使用。
若要启用监控采集及通知，应先核对自己的注册表、通知群和各事件开关。
示例模型名需换成服务实际提供的 ID，不含生产中转地址。
