# 架构

```text
QQ 群消息 / OneBot v11
          │
          ▼
llbot_bridge.py
  ├─ 确定性路由：命令、权限、去重、UTF-8、群服转发
  ├─ SocialLite：本地低成本决定“回不回”
  ├─ Sanae AI：角色卡、短回复、工具选择、视觉理解
  ├─ RCON：list/TPS/查询/受控管理命令
  ├─ BlueMap：玩家定位与网页截图
  └─ 本地状态：黑话、记忆、反馈、贴纸策略、审计
          │
          ├──────────────► Minecraft RCON / 服务端日志
          └──────────────► OneBot HTTP 回复 QQ
```

核心原则是“规则先行，模型后置”：消息去重、权限、RCON 白名单、危险确认、回声防护、
事件识别和是否唤醒模型都由本地代码完成。AI 只负责语言理解、人格化表达和受约束的工具
选择，因此空闲时几乎没有模型开销，也不需要为每条群消息创建 agent。

SCEX 当前公开配置示例以 Legacy Genesis 为默认服务器，注册表仍支持添加其他服务器。
一台服务器失败不会阻断另一台；所有事件和错误都带服务器前缀。普通玩家聊天是否回群由
监控配置决定，群到服转发可独立开关。
